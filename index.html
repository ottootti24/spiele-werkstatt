Spiele-Werkstatt 🎮

Baue hier dein eigenes kleines Spiel – direkt im Browser, ohne Installation. Unten links steht der fertige Spiel-Code. Ändere etwas, klicke auf „Spiel starten“ und schau, was passiert!

So geht's

In 4 Schritten zum eigenen Spiel

1️⃣

Code anschauen

Im linken Kasten steht das Spiel „Fange den Stern!“. Alles, was du leicht ändern kannst, steht ganz oben zwischen den Strichen.

2️⃣

Etwas ändern

Ändere zum Beispiel die Zahl bei geschwindigkeit von 3 auf 6 – oder probiere eine neue Farbe wie hotpink.

3️⃣

Spiel starten

Klicke auf „▶ Spiel starten“. Rechts siehst du sofort dein verändertes Spiel. Klicke einmal ins Spiel, damit die Pfeiltasten ⬅️➡️ funktionieren.

4️⃣

Speichern

Mit „💾 Speichern“ bleibt dein Code auch erhalten, wenn du den Tab schließt. „↩ Original“ holt das Beispiel zurück.

Code & Spiel

📝 Dein Code

Dein Code wird nur in deinem Browser gespeichert – auf deinem eigenen Laptop bleibt er also erhalten.

🕹️ Dein Spiel

Steuerung: Pfeiltasten ⬅️➡️ oder die Maus bzw. der Finger. Nach „Game over“ einfach ins Spiel klicken für eine neue Runde.

Werde Spiele-Entwickler*in

Aufgaben zum Ausprobieren

  1. Ändere geschwindigkeit = 3 auf eine andere Zahl zwischen 1 und 10. Was passiert bei 10?
  2. Gib deinem Fänger und dem Stern neue Farben: z. B. "red", "hotpink", "gold" oder Geheimfarben wie "#7c3aed".
  3. Mache den Fänger riesig: fangBreite = 80 wird zu fangBreite = 200. Ist das Spiel jetzt leichter? Und fair?
  4. Lass jeden Stern mehr Punkte geben: punkteProStern = 1 wird zu punkteProStern = 5.
  5. Profi-Aufgabe: Finde die Zeile geschwindigkeit += 0.2 und ändere sie in geschwindigkeit += 1. Wie lange schaffst du es jetzt noch, den Stern zu fangen?

Tipp: Wenn mal etwas schiefgeht – kein Problem! Klicke auf „↩ Original“ und alles ist wieder da.
